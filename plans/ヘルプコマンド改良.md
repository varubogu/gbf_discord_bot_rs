# ヘルプコマンド改良 実装仕様

## 目的
- `/help` の情報量増加に伴い、1画面固定ではなく「インデックス + ページ遷移」で案内する。
- 実行者の権限に応じて表示ページを動的に切り替える。
- 全文言を `locales/messages.yml` で管理し、既存メッセージ解決フローに統合する。

## 表示方式
- `/help` 実行時はエフェメラルで Embed を表示する。
- 初期表示はインデックスページ。
- インデックスページから各ページへ直接ジャンプできるUI（セレクタ）を提供する。
- Embed 下部に `戻る` / `進む` ボタンを配置する。
- インデックス以外のページには `目次へ戻る` ボタンを配置する。
- `custom_id` 仕様:
  - ページ送りボタン: `help_nav:{current_page}:{prev|next}`
  - 目次ジャンプセレクタ: `help_nav:jump`
  - 目次へ戻るボタン: `help_nav:to_index`
- ページ遷移はループ方式とする。
  - 先頭ページで `戻る` -> 末尾ページ
  - 末尾ページで `進む` -> 先頭ページ

## ページ粒度（機能単位）
- マルチ募集
  - 募集作成/変更/キャンセル/一覧/募集ロール関連を機能群として案内
- 定期募集
  - 作成/一覧/削除/切り替えを機能群として案内
- 自動募集
  - 一般向けは参加状況確認を案内
  - 管理系設定は管理者向け設定ページで案内
- 参照系/ユーティリティ
  - `channel_show` / `guild_settings_show` / `quest_list` / `environ_load` / `help`
- 管理者向け設定
  - チャンネル登録/解除、サーバー設定変更、クエスト有効化/無効化、募集ロール設定、スプレッドシート登録・読み書き、スケジュール運用
- 管理サーバー専用
  - `gspread_global_load` / `gspread_global_push` / `schedule_global_generate`

## 権限別表示ルール
- 一般ユーザー:
  - インデックス、マルチ募集、定期募集、自動募集、参照系/ユーティリティ
- `gbf_bot_control` ロール保持者:
  - 上記 + 管理者向け設定
- 管理サーバー（`BOT_ADMIN_SERVER_ID` 一致）:
  - `gbf_bot_control` ロール保持者に対して、さらに管理サーバー専用ページを追加表示

## 多言語対応
- 新規キー群を `help.navigator.*` で追加する。
  - インデックスタイトル/説明
  - 各ページタイトル/説明
  - 日本語説明ではコマンドの「日本語名 / 英語名」を併記し、英語説明は英語名のみを記載
  - ボタンラベル（戻る/進む/目次へ戻る）
  - 目次ジャンプセレクタのプレースホルダ
  - フッター（現在ページ/総ページ）
- 追加時は以下を必ず同時更新する。
  - `locales/messages.yml`
  - `src/services/message/message_text_id.rs`
  - `src/services/message/yaml_loader.rs`

## 互換性
- 既存 `help.embed.*` キーは削除しない（互換維持）。
- 新UIは `help.navigator.*` を使用する。

## テスト方針
- 単体テスト:
  - `help_nav` カスタムIDの正常/異常パース
  - ループ遷移（先頭戻る・末尾進む）
  - 権限条件による可視ページ集合
- 既存整合性テスト:
  - `MessageTextId` と `messages.yml` の整合性
