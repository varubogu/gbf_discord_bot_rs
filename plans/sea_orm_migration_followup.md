# Sea-ORM マイグレーション運用計画

## 1. 概要

`docs/develop/design/database/sea-orm-migration-implementation.md` の実装レポートを補完し、導入後に実施すべきフォローアップ作業を整理します。

## 2. 推奨タスク

1. 実際のデータベース環境でのマイグレーション動作テスト
2. テーブル間リレーション（外部キー制約）の動作確認
3. `sea_orm_migration` テーブルによる履歴管理の確認
4. 必要に応じた追加インデックス作成マイグレーションの検討と実装

## 3. 更新ポリシー

- 各タスク完了時に結果と残課題を追記し、運用チームで共有する。  
- マイグレーション設計方針を変更する場合は設計レポートを更新し、本計画の参照先も合わせて見直す。
