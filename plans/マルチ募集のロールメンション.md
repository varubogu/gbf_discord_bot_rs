# マルチ募集メッセージでロールに対してメンションする機能を追加

マルチバトル募集について仕様を加えたい。
まず設計書を作成・修正し、その後コード修正してください

# 概要
- マルチ募集開始時、変更時、キャンセル時のメッセージにて、guildごとに追加でロールメンションを追加する
- クエストごとのロール設定コマンドを作成する。※詳細は「ロール設定コマンド仕様」にて

# ロールについて
ロールは大きく2種類
- 全ての募集を通知するロール
- クエストに応じた通知をするロール

# データベース仕様
- データベースにはクエストID(int),連番(int),ロールID(int)、作成日時、更新日時を保持する
- クエストIDと連番のセットでPKとする
- クエストIDとロールIDのセットでユニークとする
- 高速化のためのインデックス戦略としてクエストIDのみでインデックス、クエストIDとロールIDのセットでインデックスをする
- 作成日時、更新日時は他テーブルと同じ仕様とする
- クエストID == 0 を全ての募集を通知するロール、それ以外をクエストに応じた通知をするロールとして扱う

# ロール設定コマンド仕様
- 追加コマンドと削除コマンドを用意する（パラメータの仕様は同じ）
- パラメータ1として、マルチ募集と同じようにクエスト入力欄を用意する
- パラメータ2〜7でロールを入力する（入力候補を出して選択式にしたい、一度に最大6ロールまで設定可能）
- パラメータ1と2は必須、3以降は全てオプション
- 追加コマンドで既に追加済みのロールがあった場合、そのデータはDBへinsertせず正常終了扱いとする
- 削除コマンドで既に存在しないロールがあった場合、そのデータはdeleteせず正常終了扱いとする

# マルチ募集追加、変更、削除コマンドの修正内容
- ３つのコマンドそれぞれで、クエストに応じたロールをメンションする
- DBから該当ロールを探す条件は (クエストID == 0 or クエストID == 募集するクエストのクエストID)
- 順番はクエストIDの昇順、連番の昇順
- 検索されたロールについて、検索結果を全部つなげて良い。`@マルチ募集 @天元募集`
