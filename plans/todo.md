# 課題

カテゴリにチャンネルを１つ追加します。
このチャンネルは参加申請中の時系列別に誰がどの属性で参加希望を出しているか表示するチャンネルです。
チャンネル名は「クエスト候補」とします。
日付単位で1メッセージずつ用意する必要があります ※グラブル日付ではなく、サーバーごとに設定されたタイムゾーン基準の日時

その1メッセージの中で日時、クエストごとにグルーピングして、その中で人と属性を表示します。
具体的には下記フォーマットです。

```
## <日付> <時刻> <クエスト名>
- <ユーザー名>: <属性名(複数属性可)>

## <日付> <時刻> <クエスト名>
- <ユーザー名>: <属性名(複数属性可)>
```

例
```
## 12/29 11:00 天元たる六色の理
- 山田: : 火土闇

## 12/29 11:00 ダーク・ラプチャー・ゼロ
- 山田: 火

## 12/29 12:00 天元たる六色の理
- 山田: 火
- 鈴木: 水土風

```


```
## 12/30 11:00 天元たる六色の理
- 山田: : 火土闇

## 12/30 11:00 ダーク・ラプチャー・ゼロ
- 山田: 火

## 12/30 12:00 天元たる六色の理
- 山田: 火
- 鈴木: 水土風

```
