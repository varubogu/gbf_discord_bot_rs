### 時間だけ待ち合わせる機能の詳細

```
マルチ募集v2の複数属性参加セレクトボックスと類似するコマンドですが、時間だけを募集するコマンドを追加してください。

# 仕様
- コマンドパラメータ：なし
- コマンドが実行された場合、「参加可能時間を入力してください」と表示し、セレクトボックスも表示
- セレクトボックスの中身は0～24時まで1時間単位の24個の項目（全て同時選択可能）
- セレクトボックスが選択されたらDBテーブル（新規作成）にユーザーとどの時間帯かを保存、登録後にどの時間帯に誰が参加しているかをメッセージに表示する（この際、マルチ募集の参加属性のように時間帯ごとにグルーピングする）
```

# 課題

カテゴリにチャンネルを１つ追加します。
このチャンネルは参加申請中の時系列別に誰がどの属性で参加希望を出しているか表示するチャンネルです。
チャンネル名は「クエスト候補」とします。
日付単位で1メッセージずつ用意する必要があります ※グラブル日付ではなく、サーバーごとに設定されたタイムゾーン基準の日時

その1メッセージの中で日時、クエストごとにグルーピングして、その中で人と属性を表示します。
具体的には下記フォーマットです。

```
## <日付> <時刻> <クエスト名>
- <ユーザー名>: <属性名(複数属性可)>

## <日付> <時刻> <クエスト名>
- <ユーザー名>: <属性名(複数属性可)>
```

例
```
## 12/29 11:00 天元たる六色の理
- 山田: : 火土闇

## 12/29 11:00 ダーク・ラプチャー・ゼロ
- 山田: 火

## 12/29 12:00 天元たる六色の理
- 山田: 火
- 鈴木: 水土風

```


```
## 12/30 11:00 天元たる六色の理
- 山田: : 火土闇

## 12/30 11:00 ダーク・ラプチャー・ゼロ
- 山田: 火

## 12/30 12:00 天元たる六色の理
- 山田: 火
- 鈴木: 水土風

```
