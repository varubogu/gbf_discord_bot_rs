# データベース（開発者向け）

この章は、DB設計・マイグレーション・トランザクション・スキーマ運用をまとめます。

## まず使うコマンド

```bash
# マイグレーション
cargo run -- migrate

# スキーマ整合性チェック
cargo run --bin schema_lint
```

## 最初に読む

1. 概要: `docs2/ja/開発者向け/05_データベース/概要.md`
2. 接続とトランザクション: `docs2/ja/開発者向け/05_データベース/接続とトランザクション.md`
3. マイグレーション: `docs2/ja/開発者向け/05_データベース/マイグレーション.md`
