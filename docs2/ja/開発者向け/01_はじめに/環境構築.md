# 環境構築（開発者向け）

## 前提

- Rust（プロジェクトが指定するツールチェーン）
- PostgreSQL（DevContainerまたはDockerで用意してよい）
- Discord Bot トークン
- Google スプレッドシート（グローバル用 + サーバー用）
- Google サービスアカウント鍵（JSON）

## 最短の流れ（DevContainer想定）

1. `.env` 系の雛形をコピーして値を入れる
   - `.env.app.example` → `.env.app`
   - `.env.db.example` → `.env.db`
2. サービスアカウント鍵JSONを `.local/` 配下に配置し、.env.appの `GOOGLE_SERVICE_ACCOUNT_KEY_FILE` を更新する
3. DevContainerを起動する（PostgreSQLが同時に立ち上がる想定）
4. `cargo run` で起動する

## ローカル実行の注意

- `.env` 等には機密情報が含まれます。決してコミットしないでください（.gitignoreには設定済み）
- エラーが出たら、まずログとDB接続（`DATABASE_URL`）を確認します。
