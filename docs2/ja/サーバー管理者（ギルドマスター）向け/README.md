# サーバー管理者（ギルドマスター）向けドキュメント

このフォルダは「自分のDiscordサーバー内でBotを使えるようにする」ための資料です。
サーバー内の設定（ロール、チャンネル、スプレッドシート）を扱います。

## 対象

- Discordサーバー管理者（ギルドマスター）
- `gbf_bot_control` ロールを持つ運用担当者

## 最初に読む

1. はじめに: `docs2/ja/サーバー管理者（ギルドマスター）向け/01_はじめに.md`
2. まずやること（最短）: `docs2/ja/サーバー管理者（ギルドマスター）向け/02_まずやること（最短）.md`
3. スプレッドシート運用: `docs2/ja/サーバー管理者（ギルドマスター）向け/03_スプレッドシート運用.md`
4. 困ったとき: `docs2/ja/サーバー管理者（ギルドマスター）向け/04_トラブルシューティング.md`

## Botが動いていない/更新したい場合

Bot運用（デプロイ/DB/監視/更新/障害対応）については別冊を参照してください。

- `docs2/ja/運用者向け/README.md`
