# 利用者向けドキュメント

このフォルダは「Botを使う人（一般ユーザー）」向けの資料です。
Discord初心者でも読めるように、なるべく専門用語を減らします。

## 最初に読む

1. はじめて: `docs2/ja/利用者向け/01_はじめて.md`
2. マルチ募集: `docs2/ja/利用者向け/02_マルチ募集.md`
3. 定期募集: `docs2/ja/利用者向け/03_定期募集.md`
4. 困ったとき: `docs2/ja/利用者向け/06_困ったとき.md`

## どこまでできる？

- **だれでも使える**: 募集を作る、参加する、自分の募集を変更/キャンセルする
- **サーバー管理者だけ**: チャンネル登録、スプレッドシート登録/読み込み、サーバー設定の変更
