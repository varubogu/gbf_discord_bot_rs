# 運用者向けドキュメント

このフォルダは「Botを動かし続ける」ための資料です。
ITに詳しくない人も読む前提で、用語説明と手順を丁寧に書きます。

## あなたはどちらですか？

- **Bot運用者（インフラ/デプロイ担当）**: サーバー・DB・更新・監視・障害対応まで担当
- **Discordサーバー管理者（ギルドマスター）**: 自分のDiscordサーバー内のBot設定を担当（チャンネル、スプレッドシート等）
