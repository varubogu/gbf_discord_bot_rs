# 定期募集（利用者向け）

「毎週この曜日のこの時間に募集を出す」といった自動投稿の機能です。

## できること

- 定期募集を作る
- 定期募集の一覧を見る

## まず覚える（最小）

- 「対象曜日」と「募集を出す時刻」を決めると、Botが自動で投稿します
- 自分が作成した定期募集は、自分で止めたり削除できます

## 使うコマンド

### 1) 作成: `/定期募集作成`

| 項目 | 必須 | 説明 |
|---|---:|---|
| スケジュール名 | ✅ | 分かりやすい名前（例: 天元21時） |
| クエスト名 | ✅ | 募集するクエスト |
| クエスト開始時刻 | ✅ | `HH:MM`（例: 21:00） |
| 対象曜日 | ✅ | 例: `月,水,金` / `月火水` / `毎日` |
| 募集開始時刻 | ✅ | 例: `19:00` / `2時間前` |
| マルチ攻略方法 | 任意 | クエストの設定を上書き |
| 募集開始日オフセット | 任意 | 0=当日、1=前日、2=二日前（省略時は自動） |
| 備考 | 任意 | メモ |
| 解散時刻 | 任意 | カンマ区切りで最大3つ |

### 2) 一覧: `/定期募集一覧`

- いま登録されている定期募集が表示されます

### 3) 削除: `/定期募集削除`

- 完全に消したいときに使います（取り消し不可の想定）

### 4) 一時停止/再開: `/定期募集切り替え`

- 「止めたいだけ」のときは削除ではなく切り替えがおすすめです
