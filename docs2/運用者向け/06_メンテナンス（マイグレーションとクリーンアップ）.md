# メンテナンス（マイグレーションとクリーンアップ）

## マイグレーション（DBの更新）

Botの機能追加でDB構造が変わることがあります。通常は、Botの更新時にマイグレーションを実行します。

### いつ実行する？

- Botの更新直後（または更新前）に「DB更新が必要」と案内されたとき
- 新しい機能がDBを必要とするのに、動かないとき

## データクリーンアップ（古いデータの削除）

古い募集/通知などが溜まりすぎないよう、定期的に削除します。
この処理は Bot本体とは別のメンテナンス手段で実行します。

### いつ実行する？

- 毎日深夜など、人が少ない時間帯（推奨）
- DBの容量が増え続けているとき

## 実行方法

この章で扱う実行の入口は次です。

- マイグレーション: `cargo run -- migrate`
- クリーンアップ: `docker compose run --rm maintenance`（または運用スクリプト）
