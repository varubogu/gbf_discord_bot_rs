# docs2（新ドキュメント）

この `docs2/` は、本リポジトリのドキュメントを「読む人の立場ごと」に再設計したものです。
将来的に `docs2/` を `docs/` に置き換えることを想定しています。

## まず、あなたの立場を選んでください

- 開発者向け: `docs2/ja/開発者向け/README.md`
- 運用者向け: `docs2/ja/運用者向け/README.md`
- 利用者向け: `docs2/ja/利用者向け/README.md`

## 本リポジトリにおける「運用者」の定義

運用者は大きく2種類います。

- **Bot運用者（インフラ/デプロイ担当）**: Bot全体の稼働、DB、バックアップ、更新、障害対応を担当
- **Discordサーバー管理者（ギルドマスター）**: 自分のDiscordサーバー内でのBot設定（チャンネル、スプレッドシート等）を担当

## docs2 の書き方（方針）

- 日本語で書く（ITに詳しくない人も読む前提）
- まず結論 → 手順 → つまずきポイント（FAQ）の順で書く
- コードの貼り付けで仕様を説明しない（概念・責務・流れを中心にする）
- 「どこを見れば次に進めるか」を必ずリンクで案内する
