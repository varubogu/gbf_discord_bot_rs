# トラブルシューティング（運用者向け）

## よくある症状

### 1) コマンドが反応しない

- Botが落ちていないか（プロセス/コンテナ）
- Discord側の権限が足りない設定になっていないか
- `DISCORD_TOKEN` が無効になっていないか

### 2) スプレッドシート読み込みが失敗する

- 共有設定（サービスアカウントに編集権限）があるか
- スプレッドシートID/URLが正しいか

### 3) 通知が来ない

- 通知チャンネルが登録されているか
- Botがスケジュール処理を動かせているか（ログ確認）
