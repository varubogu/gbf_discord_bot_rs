# Bot運用者向けドキュメント

このフォルダは「Botを動かし続ける（デプロイ/DB/更新/監視/障害対応）」ための資料です。
ITに詳しくない人も読む前提で、用語説明と手順を丁寧に書きます。

## サーバー内の設定をしたい場合

Discordサーバー側の設定（ロール、チャンネル、スプレッドシート）は別冊です。

- `docs/ja/サーバー管理者（ギルドマスター）向け/README.md`

## 最初に読む

1. 全体像: `docs/ja/運用者向け/01_はじめに.md`
2. 導入: `docs/ja/運用者向け/02_導入手順概要.md`
3. 設定（環境変数）: `docs/ja/運用者向け/03_導入時の設定詳細.md`
4. 起動と更新（Docker Compose）: `docs/ja/運用者向け/10_起動と更新（DockerCompose）.md`
5. 困ったとき: `docs/ja/運用者向け/08_トラブルシューティング.md`

## 目次（運用タスク別）

- 監視とログ: `docs/ja/運用者向け/07_監視とログ.md`
- メンテナンス（DB更新/クリーンアップ）: `docs/ja/運用者向け/06_メンテナンス（マイグレーションとクリーンアップ）.md`
