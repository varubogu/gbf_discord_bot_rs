# 日常運用（運用者向け）

## 毎日/毎週やること（目安）

- Botが動いているか確認する（Discord上でコマンドが反応するか、またはログ確認）
- エラーが増えていないか確認する

## 更新（アップデート）

運用方式によって手順が変わります。

- コンテナで運用している場合: イメージを更新して再起動
- それ以外の場合: 運用手順に従って更新（できればコンテナ化を推奨）

## 再起動（困ったときの基本）

- まずはBotの再起動で復旧することがあります
- 再起動しても直らない場合は、ログとDB接続を確認します

## バックアップ（推奨）

「もしDBが壊れた/消えた」に備えて、定期的にバックアップを取ります。
方法は運用環境によって異なるため、まずは運用者間で「どこに・どの頻度で・誰が」取るかを決めてください。
