# テスト（開発者向け）

この章は「何を、どの粒度でテストするか」を整理します。

## まず使うコマンド

```bash
# まずは対象だけ（名前で絞る）
cargo test test_name

# 全体
cargo test

# ignore付き（実DBが必要なもの等）も実行する
cargo test -- --ignored
```

1. テスト全体設計: `docs/ja/開発者向け/04_テスト/テスト全体設計.md`
