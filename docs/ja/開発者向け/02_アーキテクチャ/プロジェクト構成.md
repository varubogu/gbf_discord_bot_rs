# プロジェクト構成（開発者向け）

## 目的

「どこに何が置かれているか」を把握し、修正箇所を迷わないようにします。

## 重要ディレクトリ（概要）

```text
(root)
├── .tmp/                  # 一時作業領域（コミットしない）
├── db/                    # DBセットアップ用スクリプト / 初期データSQL
├── docs/                  # ドキュメント
├── locales/               # i18nメッセージ
├── migration/             # DBマイグレーション
├── src/
│   ├── bin/               # メンテナンス用バイナリ（例: cleanup）
│   ├── di/                # DI（依存性注入）/ 構成ルート
│   ├── events/            # プレゼンテーション層（Discord入力）
│   ├── facades/           # アプリケーション層（ユースケース + トランザクション境界）
│   ├── services/          # ドメイン/業務ロジック層
│   ├── repository/        # 永続化ポート層（trait + 入出力型のみ）
│   │   ├── schedule/
│   │   ├── auto_recruitment/
│   │   └── ...
│   ├── infrastructure/    # 外部システム具体実装（アダプター）
│   │   └── database/
│   │       ├── connection/      # DB接続管理
│   │       ├── session/         # DBセッション文脈（例: RLS用セッション変数）
│   │       ├── repositories/    # SeaORMによるRepositoryアダプター実装
│   │       │   ├── schedule/

│   │       │   └── ...

│   ├── utils/             # 共通ユーティリティ
│   ├── lib.rs
│   └── main.rs
├── tests/
├── tools/
└── Cargo.toml
```

## RepositoryとInfrastructureの責務

- `src/repository/**` は **ポート層**。
  - Serviceが利用する永続化インターフェース（trait）を定義する。
  - ORM固有の詳細は含めない。
- `src/infrastructure/database/repositories/**` は **アダプター層**。
  - Repository traitをSeaORMで実装する。
  - SQL/ORM依存の最適化・実装詳細を保持する。

## 移行中の一時互換方針

段階的リファクタリング期間中は次を許容する。

- `src/repository/database/**` は一時的に互換用 `pub use` として残る場合がある。
- 新規実装・新規参照は以下を利用する。
  - ポート: `src/repository/**`
  - アダプター: `src/infrastructure/database/repositories/**`
- 一時互換は最終フェーズで削除する。
