# 初期設定メッセージ

## 概要

Bot導入直後のギルド管理者が、最初に必要な設定手順を迷わず実行できるようにする案内メッセージ機能。
同一文面を以下の2経路で表示する。

- Botがギルドへ新規参加した直後（`GuildCreate.is_new = true`）
- `/init_message` コマンド実行時（再表示用）

## 目的

- 初期導入時のセットアップ漏れ（スプレッドシート未共有・通知先未設定）を減らす
- 手順をBot内に集約し、運用ドキュメント依存を下げる
- 新規参加時と再表示時で案内内容を統一する

## 表示内容

初期設定メッセージでは、最低限以下を案内する。

1. ギルド用スプレッドシートテンプレートURLを開いてコピーする
2. Botのサービスアカウントへ対象スプレッドシートの編集権限を付与する
3. `/gspread_register` でギルドの読み込み用/書き込み用URLを登録する
4. `/gspread_load` で設定をDBへ取り込む
5. `/channel_register` で通知先チャンネルを登録する

## 入力値（環境変数/ファイル）

- `GUILD_SPREADSHEET_TEMPLATE_URL`（必須）
  - 初期設定メッセージ内のテンプレートURLに使用
  - 未設定時は起動時検証でエラーとして起動を停止する
- `GOOGLE_SERVICE_ACCOUNT_KEY_FILE`（既存）
  - JSONの `client_email` を抽出し、共有先メールアドレスとして表示
  - 取得失敗時はフォールバック文字列を表示

## 挙動仕様

### 1. ギルド参加時

- トリガー: `FullEvent::GuildCreate`
- 条件:
  - `is_new = true` の場合のみ初期設定メッセージ送信対象
  - `is_new = false`（Bot再起動時のギルド再受信）は送信しない
- 送信先:
  - `guild.system_channel_id` が存在する場合のみ送信
  - 未設定/送信失敗時はログに記録して継続（イベント処理全体は失敗させない）

### 2. `/init_message` コマンド

- 実行場所: ギルド内のみ
- 権限: `gbf_bot_control` ロール保持者
- 応答: 実行チャンネルへ初期設定メッセージ本文を送信

## レイヤー責務

- events
  - 初期設定メッセージ本文の組み立て
  - ギルド参加時送信/コマンド送信の起点制御
- facades/services/repository
  - 既存の `/gspread_register`・`/gspread_load`・`/channel_register` の責務を変更しない

## メッセージ管理

- ユーザー向け本文は `locales/messages.yml` で管理（`messages.init_guide`）
- コード側は `MessageTextId` 経由で取得
- ギルドごとのロケール解決は既存の `guild_settings.locale` ルールに従う

## テスト観点

- 文字列組み立て:
  - テンプレートURLの環境変数上書き/未設定時の欠損扱い
  - サービスアカウントJSONからの`client_email`抽出成功/失敗
- メッセージ整合性:
  - `MessageTextId` と `locales/messages.yml` のキー一致
  - `yaml_loader` で `messages.init_guide` が解決可能
