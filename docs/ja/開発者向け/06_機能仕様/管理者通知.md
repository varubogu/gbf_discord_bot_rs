# 管理者通知機能

## 概要

管理者通知機能は、bot実行中に発生したエラーや設定不足を、各ギルドで設定した
Discordチャンネルに通知する機能です。`gbf_bot_control` ロールを持つギルド管理者が
このチャンネルを監視することで、botの稼働状況を把握できます。

## チャンネル種別

- `channel_type = 5`（`src/models/entities/master/channel_types.rs` の `GuildChannelType::AdminNotification`）
- ギルドごとに `guild_master.guild_channels` で登録
- `/channel_register` Discord スラッシュコマンドで設定

## 通知を送信するケース

- イベントスケジュール通知チャンネルなど、必要なチャンネルが未設定の場合
- バックグラウンドタスク実行中にエラーが発生し、ギルド管理者に報告が必要な場合
- その他、botがギルド運営者への通知が必要と判断した状況

## チャンネル未設定時の動作

`guild_master.guild_channels` に対象ギルドの `channel_type = 5` が登録されていない場合、
サービスは `warn!` ログを出力したうえで `Ok(())` を返します。
通知失敗がメイン処理の失敗に波及しないようにするためです。

## 実装

この機能は**サービスのみ**の構成です（専用ファサードはありません）。
`AdminNotificationService` は他のファサードから呼び出され、呼び出し元がトランザクションを
提供します。

| レイヤー | ファイル | 責務 |
| --- | --- | --- |
| enum | `src/models/entities/master/channel_types.rs` | `GuildChannelType::AdminNotification = 5` |
| サービス | `src/services/channel/admin_notification_service.rs` | DBからチャンネルID取得・Discordゲートウェイ呼び出し |

> **マイグレーション不要。** `master.channel_types` の id=5 レコードはこのコードの外で
> 管理されている（既存のマスターデータ）ため、スキーマ変更は不要です。

## データフロー

```
呼び出し元ファサード（スケジューラー等）
  ├─ トランザクション開始
  └─ AdminNotificationService::notify_admin(&txn, guild_id, message)
       ├─ GuildChannelRepository::get_by_guild_and_type_with_txn(guild_id, 5)
       │    └─ None の場合 → warn ログ出力、Ok(()) を返す
       └─ DiscordMessageGateway::send_message(channel_id, message)
```
