# ヘルプコマンド

## 概要

`/help` は、利用可能な機能をページ単位で案内するエフェメラル表示のコマンドです。  
従来の単一Embedではなく、インデックス（目次）+ ページ遷移UIで表示します。

## 目的

- 機能増加に伴うヘルプ可読性の向上
- 実行者権限に応じた表示内容の最小化
- 多言語文言を `locales/messages.yml` に一元化

## コマンド仕様

- スラッシュコマンド: `/help`
- 応答: エフェメラル
- 初期表示: インデックス（目次）ページ

## 画面仕様

### インデックス（目次）ページ

- 表示可能ページの一覧を表示する
- ページへ直接移動するセレクタを表示する
- `戻る` / `進む` ボタンで前後ページに遷移できる

### 各詳細ページ

- 機能別のコマンド説明を表示する
- `戻る` / `進む` に加えて `目次へ戻る` ボタンを表示する

### 遷移ルール

- ループ遷移（循環）
  - 先頭ページで `戻る` -> 末尾ページ
  - 末尾ページで `進む` -> 先頭ページ

## 権限別表示

### 一般ユーザー

- インデックス
- マルチ募集
- 定期募集
- 自動募集
- 参照系 / ユーティリティ

### `gbf_bot_control` ロール保持者

- 上記に加えて 管理者向け設定

### 管理サーバー（`BOT_ADMIN_SERVER_ID`）かつ `gbf_bot_control`

- 上記に加えて 管理サーバー専用

## コンポーネントID仕様

- ページ送り: `help_nav:{current_page}:{prev|next}`
- ページジャンプ（セレクタ）: `help_nav:jump`
- 目次へ戻る: `help_nav:to_index`

不正な `custom_id` は安全に中断し、ユーザー体験を壊さない形で処理する（警告ログ + defer）。

## 多言語・文言管理

- 新UIは `help.navigator.*` を使用する
- 既存 `help.embed.*` は互換性のため維持する
- 日本語説明ではコマンドの「日本語名 / 英語名」を併記する
- 英語説明では英語コマンド名のみを記載する
