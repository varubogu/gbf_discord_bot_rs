# 開発ルール（必読）

この章は「迷ったらルールに戻る」ための場所です。

## 最優先（守ること）

- コメント/ドキュメント/エラーメッセージは日本語（コードの識別子は英語）
- `events → facades → services → repository` の依存方向を破らない
- トランザクション境界は Facade のみ
- `unwrap()` を本番コードで使わない
