# まずやること（最短）

ここでは「自分のDiscordサーバー内でBotを使えるようにする」ための設定を、できるだけ短くまとめます。

## まずやること（最短）

1. `gbf_bot_control` ロールを作る（Bot設定を触れる人にだけ付ける）
2. サーバー用スプレッドシートを用意し、サービスアカウントに共有する
3. スプレッドシートを登録する
4. チャンネルを登録する
5. スプレッドシートを読み込む（反映）

## 1) `gbf_bot_control` ロールを作る

- ロール名は `gbf_bot_control` を推奨します（分かりやすさ重視）
- 付与する人は最小にしてください（誤操作を防ぐため）

## 2) サーバー用スプレッドシートを用意して共有する

- Botがスプレッドシートを読めるように、**サービスアカウント**へ共有設定を行います
- 共有先（メールアドレス）が分からない場合は、Bot運用者に確認してください

### 共有設定の目安

- 権限は原則「編集者」
- スプレッドシート（ファイル）単位で共有

## 3) スプレッドシートを登録する

- Botに「このサーバーでは、このスプレッドシートを使う」ことを登録します
- 入力はURLでもIDでも構いません（運用方法に合わせてください）

## 4) チャンネルを登録する

- 通知や募集など、Botがメッセージを送るチャンネルを登録します
- Botがそのチャンネルを閲覧/投稿できる権限を持っていることを確認してください

## 5) スプレッドシートを読み込む（反映）

- 登録したスプレッドシートの内容をDBへ反映します
- 初期セットアップ時や、設定変更後に行います

## 注意（事故を防ぐ）

- `gbf_bot_control` は強い権限です。付与する人を最小にしてください
- 設定変更後は「スプレッドシート読み込み」を忘れないでください（反映されません）
