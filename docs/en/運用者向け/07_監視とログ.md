# Monitoring and Logs (Operator)

## Purpose

- Detect issues quickly (e.g., notifications not being sent)
- Make it possible to trace what happened (logs)

## What to check first

- Bot logs (are errors increasing?)
- DB storage size (is it growing rapidly?)

## Tips for reading logs

- First, check whether `error` logs are repeating.
- Also check the “operation right before the error” (loading spreadsheets, creating recruitments, etc.).
