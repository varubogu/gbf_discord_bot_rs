# FAQ (User)

## Q: I can’t find commands

- If no command suggestions appear after typing `/`, the bot may not be added to the server.
  Make sure you type half-width `/` (not full-width `／`).
- Ask your server administrator first.

## Q: I don’t know how to fill in inputs

Slash commands show input fields on the screen. If you’re unsure, try something close to the examples first.
