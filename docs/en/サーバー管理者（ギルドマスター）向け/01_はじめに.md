# Introduction (Server Administrator)

## Purpose

This page helps you understand the overall steps required to “make the bot usable in your Discord server”.
As a server administrator, you are responsible for **server-side configuration** (roles, channels, spreadsheets).

## Responsibilities vs. the bot operator

### What you (server admin) handle

- Create and assign the `gbf_bot_control` role
- Register/load the server spreadsheet
- Register notification channels
- Manage server-specific settings (e.g., quest enable/disable)

### What the bot operator (infra/deploy) handles

- Start/update the bot (deploy)
- Manage the DB (PostgreSQL): backup/restore/migrations
- Monitoring, log checks, incident response
- Manage the global spreadsheet

## What to remember (minimum)

- Configuration is split into **environment variables** and **spreadsheets**.
- Spreadsheets are split into **global (shared across servers)** and **per-server (guild)**.
- This documentation mainly focuses on the **per-server (guild) spreadsheet**.
