# プロジェクト構成（開発者向け）

## 目的

「どこに何が置かれているか」を把握し、修正箇所を迷わないようにします。

## 重要ディレクトリ（概要）

```
(root)
├── .tmp      # 一時的な作業用。この中身はコミットしないので検証用に自由に使って良い。
├── db/       # DBの設定用
│   ├── sh/   # データベースセットアップ用のシェルスクリプト 
│   ├── sql/  # データベースの初期データ設定用SQL
├── docs/     # ドキュメント格納先
├── locales/  # 多言語対応メッセージファイルを格納
│   └── messages.yml  # 日本語メッセージ定義（rust-i18n用）
├── migration/        # DBマイグレーションのマイグレーションファイル
├── src            # ソースコードの格納先
│   ├── bin/       # クリーンアップ用の処理
│   │   └── cleanup.rs   # データクリーンアップバッチのエントリーポイント
│   │   di/        # 依存性注入（DI）コンテナモジュール
│   │   errors/        # エラー定義
│   ├── events/            # discord botのイベント・インタラクション全般
│   │   ├── handlers/      # discord botのイベント（on_messageやon_reaction_add）を定義
│   │   ├── interactions/  # discord botのインタラクション全般
│   │   │   ├── command_interactions/   # インタラクションのうちユーザーのコマンド依存 
│   │   │   │   └── slash/              # スラッシュコマンド定義
│   │   │   ├── components/             # コンポーネントインタラクション
│   │   │   └── modal/                  # モーダルインタラクション
│   │   └── handler.rs     # discord botのイベント・インタラクション全般
│   ├── facades/           # Facade層。主にユーザーの何かしらのアクション（events、インタラクション、スケジュール起動）から呼び出される
│   ├── gateway/           # poise/serenityとビジネスロジック層の間のインターフェースを定義する。
│   ├── infrastructure/    # インフラストラクチャ層。外部APIやDBなどの依存関係を抽象化する。
│   │   └── database/      # DBへのCRUD操作の処理（sea-ormベース）
│   ├── models/            # facades,servicesで使用する構造体を定義
│   │   └── entities/      # DBのテーブル定義・マッピング（src/models/直下のモデルとは相互変換が可能）
│   ├── presenter/         # プレゼンター層。ユーザーに見せるUIを定義し、poise/serenityの型に変換する。

│   ├── repository/     # データの永続化（保存・読み込み）
│   │   └── database/   # DBへのCRUD操作の処理（sea-ormベース）
│   ├── services/                   # 単一の処理を提供するサービス層
│   │   ├── battle_recruitment/     # マルチバトル募集・通知サービス
│   │   ├── environment/            # 環境変数読み込み
│   │   ├── message/                # メッセージの抽象化層（rust-i8n＋サーバーごとに独自で上書き可能なメッセージ）
│   │   └── permission/             # discordパーミッションに関するサービス
│   ├── types/        # type/enumの定義（※ドメインオブジェクトはsrc/models/に配置する
│   ├── utils/        # プロジェクト内で使う汎用処理
│   ├── lib.rs        # ライブラリクレートとしての最上位。主にテストの時のモジュール宣言用
│   └── main.rs       # エントリポイント
├── target            # cargoのビルド等の出力先
├── tests             # テストコードの格納先
│   ├── integration/  # 結合テストのテストコード
│   ├── system/       # システムテストのテストコード
│   └── mod.rs        # テストコードのモジュール宣言
├── tools/            # ツールの格納先
│   └── schema_lint/  # schemaの一貫性チェックツール
├── .env.app              # 開発時の環境変数定義（重要な認証情報が含まれるため読み込み禁止）
├── .env.app.example      # 開発時の環境変数定義の見本
├── .env.db              # DBコンテナの環境変数定義
├── .env.db.example      # DBコンテナの環境変数定義の見本
├── .env.maintenance     # メンテナンス実行用の環境変数定義
├── .env.maintenance.example  # メンテナンス実行用の環境変数定義の見本
├── Cargo.lock        # Cargoインストール済みクレート
└── Cargo.toml        # Cargo設定ファイル
```
