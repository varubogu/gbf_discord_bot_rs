# Troubleshooting (User)

## Check first

- Is the bot online (does it show in the member list)?
- Are you running the command in the right channel? (depends on server rules)

## Common causes

- The server administrator has not completed initial setup (channel registration, etc.)
- You sent the command with required fields left empty

## If it still doesn’t work

Ask your server administrator (someone with the `gbf_bot_control` role).
