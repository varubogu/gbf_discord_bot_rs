## Discordのスラッシュコマンドとは

スラッシュコマンドは、Discordでボットに命令を送る機能です。チャット欄に `/` （スラッシュ）を入力すると、利用できるコマンドの一覧が表示されます。

### コマンドの入力方法

1. **チャット欄に `/` を入力する**
   利用可能なコマンド一覧が自動的に表示されます。

2. **コマンド名を選択または入力する**
   例: `/マルチバトル募集2` と入力すると、マルチバトル募集コマンドが選択されます。

3. **必要なパラメータを入力する**
   コマンドによっては、クエスト名や日時などの情報を入力する必要があります。入力欄が表示されるので、指示に従って入力してください。

4. **送信ボタン（Enterキー）を押して実行する**
   入力が完了したら、Enterキーを押してコマンドを実行します。

---

## 基本的な使い方

### 例: マルチバトル募集を作成する

1. チャット欄に `/マルチバトル募集2` と入力します。
2. 以下のパラメータを入力します：
   - **クエスト名**: 募集したいクエストを選択します（例: 進撃せし究極の竜HL）
   - **クエスト出発日時**: 出発する日時を入力します（例: 21:00、今日21時、明日22:00）
   - **マルチ攻略方法**（任意）: 攻略方法を選択します（未入力の場合はクエストのデフォルト値）
   - **解散時刻**（任意）: 解散する時刻を入力します（例: 1時間前, 21:00, 2日前）
3. Enterキーを押すと、募集メッセージが投稿されます。

## 利用可能なコマンド

### マルチバトル募集

サーバー内でマルチバトルの参加者を募集できます。

#### `/マルチバトル募集2` （ボタン版）

最新のボタン式募集機能です。参加者がボタンをクリックすることで簡単に参加できます。

**パラメータ:**

| パラメータ名 | 必須 | 説明 | 例 |
|------------|------|------|-----|
| クエスト名 | ✅ | 募集するクエスト名またはクエスト別名 | 進撃せし究極の竜HL |
| クエスト出発日時 | ✅ | クエストの出発日時 | 21:00、今日21時、明日22:00 |
| マルチ攻略方法 | ❌ | 攻略方法（省略時はクエストのデフォルト値） | ALL_ELEMENT、RELIC_BUSTER など |
| 解散時刻 | ❌ | 解散する時刻（カンマ区切り、最大3つ） | 1時間前, 21:00, 2日前 |

**日時の入力方法:**

以下のような柔軟な入力が可能です：

- **時刻のみ**: `21:00`、`22時`、`22時30分`
- **日付+時刻**: `明日21:00`、`1/15 21:00`
- **相対時刻**: `30分後`、`1時間後`、`1時間半後`
- **日数指定**: `2日後の21時`
- **全角数字・漢数字**: `二一:〇〇`、`二十一時`なども対応

**マルチ攻略方法の種類:**

| 種類 | 説明 | リアクション |
|-----|------|------------|
| DEFAULT | 通常の攻略方法（自由） | ✋ 挙手のみ |
| ALL_ELEMENT | 6属性の攻略方法 | 🔴🔵🟤🟢🟡🟣⚪ 火水土風光闇+全属性対応 |
| SYSTEM | システム狩り | ✋ 挙手のみ |
| RELIC_BUSTER | 全員レリックバスターのシステム狩り | ✋ 挙手のみ |
| SUPER_ULTIMATE_BAHAMUT | スパバハ用（6属性+10%担当） | 🔴🔵🟤🟢🟡🟣⚪🔟 |

> **注意**: 属性絵文字はサーバー管理者によってカスタム絵文字に変更されている場合があります。

**使用例:**

```
/マルチバトル募集2 クエスト名:進撃せし究極の竜HL クエスト出発日時:21:00
```

```
/マルチバトル募集2 クエスト名:進撃せし蒼き究極の竜HL クエスト出発日時:明日22:00 マルチ攻略方法:ALL_ELEMENT
```

```
/マルチバトル募集2 クエスト名:黒銀の翼HL クエスト出発日時:今日21時 解散時刻:1時間前, 20:00
```

#### `/recruit_cancel`（募集キャンセル）

自分が作成した募集をキャンセルします。

**使用方法:**

募集メッセージに対して右クリック → 「アプリ」→ 「募集キャンセル」を選択

または、募集メッセージのIDを指定してコマンドを実行します。

---

#### `/recruit_change`（募集内容変更）

自分が作成した募集の内容を変更します。

**使用方法:**

募集メッセージに対して右クリック → 「アプリ」→ 「募集内容変更」を選択

または、募集メッセージのIDを指定してコマンドを実行します。

### 定期募集の確認

定期的に自動投稿される募集スケジュールを確認できます。

#### `/定期募集一覧`

登録されている定期募集スケジュールを一覧表示します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 | デフォルト |
|------------|------|------|-----------|
| 全員表示 | ❌ | サーバー全員のスケジュールを表示するか | true（全員表示） |

**使用例:**

```
/定期募集一覧
```

サーバー全員の定期募集スケジュールが表示されます。

```
/定期募集一覧 全員表示:false
```

自分が作成した定期募集スケジュールのみが表示されます。

**表示される情報:**

- スケジュール名
- クエスト名
- 対象曜日
- クエスト開始時刻
- 募集開始時刻
- 解散時刻（設定されている場合）
- 作成者
- 有効/無効状態

## よくある質問

### Q: コマンドが表示されません

A: 以下を確認してください：
- チャット欄に `/` を入力していますか？
- Botがサーバーに追加されていますか？
- チャンネルの権限でBotのメッセージが見えるようになっていますか？

### Q: 募集が投稿されません

A: 以下を確認してください：
- 必須パラメータ（クエスト名、出発日時）を入力しましたか？
- クエスト名は正しいですか？（オートコンプリートで候補が表示されます）
- 日時の入力形式は正しいですか？

### Q: 日時の入力方法がわかりません

A: 以下のような形式で入力できます：
- `21:00` （今日の21時）
- `明日21:00` （明日の21時）
- `1/15 21:00` （1月15日の21時）
- `30分後` （30分後）
- `1時間半後` （1時間30分後）

### Q: 募集を間違えて作成してしまいました

A: 募集メッセージを右クリック → 「アプリ」→ 「募集キャンセル」でキャンセルできます。

### Q: クエスト名が選択肢に表示されません

A: クエスト名は管理者がスプレッドシートで管理しています。サーバー管理者に追加をリクエストしてください。
