## 初期セットアップ

サーバーでBotを使用開始するには、以下の手順で初期設定を行います。

### 1. 管理者ロールの設定

1. Discordサーバーで `gbf_bot_control` という名前のロールを作成します。
2. Bot管理権限を持つメンバーにこのロールを付与します。

> **重要**: このロールを持つメンバーは、Botの全ての管理機能にアクセスできます。信頼できるメンバーのみに付与してください。

### 2. スプレッドシートの登録

Botの機能を使用するには、Googleスプレッドシートを登録する必要があります。

```
/スプレッドシート登録 読み込み用スプレッドシート:<URL> 書き込み用スプレッドシート:<URL>
```

詳細は [スプレッドシート連携](#スプレッドシート連携) を参照してください。

### 3. 通知チャンネルの設定

各種通知を送信するチャンネルを設定します。

```
/channel_register チャンネル種別:<種別> チャンネル:<チャンネル>
```

詳細は [チャンネル管理](#チャンネル管理) を参照してください。

### 4. スプレッドシートからデータを読み込み

登録したスプレッドシートからクエストデータなどを読み込みます。

```
/スプレッドシート読み込み
```

これで初期セットアップは完了です。

## 権限について

### `gbf_bot_control` ロール

このロールを持つメンバーは、以下の管理機能にアクセスできます：

- スプレッドシートの登録・読み込み・書き込み
- チャンネルの登録・登録解除
- 環境変数の再読み込み
- クエストの有効化・無効化
- サーバー設定の変更

### 一般ユーザーとの違い

一般ユーザーは以下の基本機能のみ使用できます：

- マルチバトル募集の作成・キャンセル・変更（自分が作成したもののみ）
- 定期募集の作成・一覧表示・削除（自分が作成したもののみ）
- ヘルプの表示

## スプレッドシート連携

Botは、Googleスプレッドシートを使ってクエスト情報、環境変数、メッセージテンプレートなどを管理します。

### スプレッドシートの登録

#### `/スプレッドシート登録`

サーバー用のスプレッドシートを登録します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| 読み込み用スプレッドシート | ✅ | 読み込み専用のスプレッドシートURL（またはID） |
| 書き込み用スプレッドシート | ✅ | 書き込み専用のスプレッドシートURL（またはID） |

**使用例:**

```
/スプレッドシート登録 読み込み用スプレッドシート:https://docs.google.com/spreadsheets/d/ABC123... 書き込み用スプレッドシート:https://docs.google.com/spreadsheets/d/XYZ789...
```

> **ヒント**: スプレッドシートIDだけでも登録可能です（例: `ABC123...`）

### スプレッドシートの読み込み

#### `/スプレッドシート読み込み`

登録したスプレッドシートからデータを読み込み、データベースに反映します。

**読み込まれるデータ:**

- クエスト情報
- クエスト別名
- マルチ募集種類
- 環境変数
- メッセージテンプレート
- イベントスケジュール
- イベント期間内詳細スケジュール

**使用例:**

```
/スプレッドシート読み込み
```

**注意事項:**

- 読み込みには時間がかかる場合があります（数秒〜数十秒）
- 読み込み中にエラーが発生した場合、エラーメッセージが表示されます
- 読み込み完了後、成功・失敗した行数が表示されます

### スプレッドシートへの書き込み

#### `/スプレッドシート書き込み`

データベースのデータを書き込み用スプレッドシートに書き出します。

**書き込まれるデータ:**

- 募集履歴
- 統計情報

**使用例:**

```
/スプレッドシート書き込み
```

### スプレッドシートの構造

スプレッドシートには以下のシートが必要です：

#### グローバル設定（Bot運用者が管理）

- `クエスト`: クエストの基本情報
- `クエスト別名`: クエストの別名定義
- `マルチ募集種類`: 募集タイプの定義
- `(global)イベントスケジュール`: 全サーバー共通のイベント
- `(global)イベント期間内詳細スケジュール`: グローバルイベントの詳細

#### サーバー固有設定（サーバー管理者が管理可能）

- `環境変数`: サーバー固有の設定
- `メッセージ`: カスタムメッセージテンプレート
- `(guild)イベントスケジュール`: サーバー独自のイベント
- `(guild)イベント期間内詳細スケジュール`: サーバーイベントの詳細

## チャンネル管理

Botが各種通知を送信するチャンネルを管理します。

### チャンネルの登録

#### `/channel_register`

通知チャンネルを登録します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| チャンネル種別 | ✅ | チャンネルの用途（オートコンプリートで選択） |
| チャンネル | ✅ | 登録するDiscordチャンネル |

**使用例:**

```
/channel_register チャンネル種別:募集通知 チャンネル:#マルチ募集
```

### チャンネルの登録解除

#### `/channel_unregister`

登録したチャンネルを解除します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| チャンネル種別 | ✅ | 解除するチャンネルの種別 |

**使用例:**

```
/channel_unregister チャンネル種別:募集通知
```

### チャンネル設定の確認

#### `/channel_show`

現在のチャンネル設定を確認します。

**使用例:**

```
/channel_show
```

登録されている全てのチャンネルと、未設定のチャンネル種別が表示されます。

## 定期募集管理

定期的に自動投稿される募集スケジュールを管理します。

### 定期募集の作成

#### `/定期募集作成`

指定した曜日と時刻に自動的にマルチ募集を投稿するスケジュールを作成します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 | 例 |
|------------|------|------|-----|
| スケジュール名 | ✅ | スケジュールの識別名 | 天元21時 |
| クエスト名 | ✅ | 募集するクエスト | 進撃せし究極の竜HL |
| クエスト開始時刻 | ✅ | クエスト開始時刻（HH:MM形式） | 22:00 |
| 対象曜日 | ✅ | 募集する曜日 | 月,水,金 / 毎日 |
| 募集開始時刻 | ✅ | 募集を投稿する時刻 | 20:00 / 2時間前 |
| マルチ攻略方法 | ❌ | 攻略方法 | ALL_ELEMENT |
| 募集開始日オフセット | ❌ | 募集開始日のオフセット（0=当日、1=前日） | 0 |
| 備考 | ❌ | メモ | 毎週定期 |
| 解散時刻 | ❌ | 解散時刻 | 1時間前, 21:00 |

**曜日の入力方法:**

以下の形式で入力できます：

- カンマ区切り: `月,水,金`
- スペース区切り: `火 木`
- 連続入力: `月火水`、`金土日`
- 毎日: `毎日`

**募集開始時刻の入力方法:**

以下の形式で入力できます：

- 絶対時刻: `20:00`
- 相対時刻: `2時間前`、`1時間半前`

**使用例:**

```
/定期募集作成 スケジュール名:天元21時 クエスト名:進撃せし究極の竜HL クエスト開始時刻:21:00 対象曜日:月,水,金 募集開始時刻:2時間前
```

```
/定期募集作成 スケジュール名:毎日アルバハ クエスト名:アルティメットバハムートHL クエスト開始時刻:22:00 対象曜日:毎日 募集開始時刻:20:00 マルチ攻略方法:SYSTEM
```

### 定期募集の一覧表示

#### `/定期募集一覧`

登録されている定期募集スケジュールを一覧表示します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 | デフォルト |
|------------|------|------|-----------|
| 全員表示 | ❌ | サーバー全員のスケジュールを表示するか | true |

**使用例:**

```
/定期募集一覧
```

### 定期募集の有効化/無効化

#### `/recruitment-schedule-toggle`

定期募集スケジュールを一時停止または再開します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| スケジュールID | ✅ | 変更するスケジュールのID（一覧で確認） |

**使用例:**

```
/recruitment-schedule-toggle スケジュールID:123
```

### 定期募集の削除

#### `/recruitment-schedule-delete`

定期募集スケジュールを削除します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| スケジュールID | ✅ | 削除するスケジュールのID（一覧で確認） |

**使用例:**

```
/recruitment-schedule-delete スケジュールID:123
```

## クエスト管理

サーバー内で利用可能なクエストを管理します。

### クエスト一覧の表示

#### `/quest_list`

現在利用可能なクエストの一覧を表示します。

**使用例:**

```
/quest_list
```

有効/無効状態、クエスト名、デフォルトの攻略方法などが表示されます。

### クエストの有効化

#### `/quest_enable`

無効化されているクエストを有効化します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| クエスト名 | ✅ | 有効化するクエスト |

**使用例:**

```
/quest_enable クエスト名:進撃せし究極の竜HL
```

### クエストの無効化

#### `/quest_disable`

クエストを一時的に無効化します（募集できなくなります）。

**パラメータ:**

| パラメータ名 | 必須 | 説明 |
|------------|------|------|
| クエスト名 | ✅ | 無効化するクエスト |

**使用例:**

```
/quest_disable クエスト名:進撃せし究極の竜HL
```

> **用途**: イベント期間外など、一時的に募集を制限したい場合に使用します。

## サーバー設定

サーバー固有の設定を管理します。

### 設定の確認

#### `/guild_settings_show`

現在のサーバー設定を確認します。

**使用例:**

```
/guild_settings_show
```

タイムゾーン、デフォルト開始時刻、属性絵文字などの設定が表示されます。

### 設定の変更

#### `/guild_settings_set`

サーバー設定を変更します。

**パラメータ:**

| パラメータ名 | 必須 | 説明 | 例 |
|------------|------|------|-----|
| 設定キー | ✅ | 変更する設定項目 | timezone |
| 設定値 | ✅ | 新しい値 | Asia/Tokyo |

**主な設定項目:**

| 設定キー | 説明 | 例 |
|---------|------|-----|
| timezone | タイムゾーン | Asia/Tokyo |
| default_start_time | デフォルト開始時刻 | 21:00 |
| fire_emoji | 火属性の絵文字 | 🔴 または <:custom:123456> |
| water_emoji | 水属性の絵文字 | 🔵 |
| earth_emoji | 土属性の絵文字 | 🟤 |
| wind_emoji | 風属性の絵文字 | 🟢 |
| light_emoji | 光属性の絵文字 | 🟡 |
| dark_emoji | 闇属性の絵文字 | 🟣 |

**使用例:**

```
/guild_settings_set 設定キー:timezone 設定値:Asia/Tokyo
```

```
/guild_settings_set 設定キー:fire_emoji 設定値:<:fire:123456789012345678>
```

> **ヒント**: カスタム絵文字を使用する場合、絵文字の前に `\` を付けて投稿すると、絵文字IDが取得できます。

## トラブルシューティング

### スプレッドシートの読み込みに失敗する

**原因:**

- スプレッドシートのURLが間違っている
- Botにスプレッドシートへのアクセス権限がない
- スプレッドシートのシート名が正しくない

**対処法:**

1. スプレッドシートのURLを確認する
2. スプレッドシートの共有設定で「リンクを知っている全員が閲覧可」になっているか確認
3. シート名が仕様通りになっているか確認（大文字小文字も区別されます）

### チャンネル登録ができない

**原因:**

- `gbf_bot_control` ロールを持っていない
- チャンネル種別が存在しない

**対処法:**

1. 自分に `gbf_bot_control` ロールが付与されているか確認
2. チャンネル種別のオートコンプリートで正しい種別を選択

### 定期募集が投稿されない

**原因:**

- スケジュールが無効化されている
- クエストが無効化されている
- 通知チャンネルが設定されていない
- 時刻設定が間違っている

**対処法:**

1. `/定期募集一覧` でスケジュールが有効か確認
2. `/quest_list` でクエストが有効か確認
3. `/channel_show` でチャンネルが設定されているか確認
4. スケジュールの時刻設定を再確認

### 環境変数の変更が反映されない

**原因:**

- スプレッドシートを更新したが、読み込みを実行していない

**対処法:**

1. スプレッドシートで環境変数を更新
2. `/スプレッドシート読み込み` を実行
3. 必要に応じて `/environ_load` でメモリ上の環境変数を再読み込み

## その他の管理コマンド

### 環境変数の再読み込み

#### `/environ_load`

データベースから環境変数をメモリに再読み込みします。

**使用例:**

```
/environ_load
```

> **用途**: スプレッドシートから環境変数を読み込んだ後、Botを再起動せずに設定を反映させる場合に使用します。

### スケジュール履歴の確認

#### `/schedule_history`

過去のスケジュール実行履歴を確認します。

**使用例:**

```
/schedule_history
```

### スケジュール統計の確認

#### `/schedule_stats`

スケジュールの実行統計を確認します。

**使用例:**

```
/schedule_stats
```

## セキュリティとベストプラクティス

### ロール管理

- `gbf_bot_control` ロールは必要最小限のメンバーにのみ付与する
- 定期的にロールを持つメンバーを確認し、不要になった場合は剥奪する

### スプレッドシート管理

- 読み込み用と書き込み用でスプレッドシートを分ける
- 編集権限は管理者のみに限定する
- 定期的にバックアップを取る

### チャンネル設定

- 各通知チャンネルは明確に分ける
- 通知が多すぎる場合は、専用チャンネルを作成する
